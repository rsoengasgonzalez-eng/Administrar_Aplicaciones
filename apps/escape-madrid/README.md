# EscapeMadrid · integrada

La aplicación consulta `/api/escape/rooms`. El Worker obtiene elementos reales etiquetados como `leisure=escape_game` o `attraction=escape_room` en OpenStreetMap mediante Overpass API.

No se incluyen fichas semilla ni precios, aforos, duraciones, temáticas o valoraciones inventadas. Solo se muestran los campos publicados en la fuente, con enlace al elemento original y a la ubicación.
